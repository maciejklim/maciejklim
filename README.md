# Hi there 👋

I build tools for security teams, system administrators, and MSPs. Some are public.

Most of my projects exist because I got tired of performing the same task more than twice. A few are public. Occasionally I write things down on my [blog](https://maciejklim.github.io/).

## What I Build

Most projects fall into one of three categories:

- Security operations
- Microsoft 365 administration
- MSP workflow automation

My goal is not to replace existing platforms. Good tools fill gaps, connect systems together, and eliminate repetitive work.

## Philosophy

Good tools remove friction.

I am less interested in building another dashboard and more interested in helping people answer questions faster.

If a technician can save thirty minutes of investigation time, if an analyst can avoid ten clicks, or if an administrator can automate a repetitive task, the project is probably worth building.
